🎮 AACR - Артефакты и Проклятые Реликвии
📖 Описание:

AACR - Артефакты и Проклятые Реликвии - это мощный и уникальный плагин для Minecraft серверов, который добавляет в игру захватывающую систему мистических предметов с активными способностями. Погрузитесь в мир, где каждый артефакт обладает невероятной силой, но также может быть проклят и нести в себе опасность!

✨ Основные возможности
🔮 Система Артефактов
Активные способности - каждый артефакт имеет уникальную мощную способность
Кулдауны - баланс использования для честной игры
Побочные эффекты - сила всегда имеет свою цену
Примеры:
Клинок Измерений - телепорт вперёд на 7 блоков
Амулет Небытия - временная неуязвимость с перезарядкой
☠️ Проклятые Реликвии
Негативные эффекты - цена силы может быть фатальной
Мощное оружие - используйте проклятия против врагов
Примеры:
Сердце Чумы - распространяет болезнь на окружающих
Глаз Пустоты - ослепляет и замедляет всех врагов в радиусе
⚗️ Система Очищения и Заражения
Трансформация предметов - очищайте проклятые реликвии или заражайте артефакты
Ресурсные затраты - для трансформации требуются материалы и XP
Риск и награда - шанс неудачи с возможностью поломки предмета
Индивидуальное меню - удобный интерфейс для всех операций
🛠️ Глубокая настройка
Полная кастомизация - настройте все способности, эффекты и кулдауны
Добавление своих предметов - создавайте уникальные артефакты через конфиги
Гибкие параметры - контролируйте каждый аспект системы
📊 Система логирования
Отслеживание использования - мониторинг всех действий с артефактами
Борьба с читерами - контроль владения и использования предметов
Статистика сервера - сбор данных для балансировки
🎯 Особенности

🛡️ Безопасный - система кулдаунов и логирования
